# Public Docs

This directory now keeps only the public-facing product and architecture docs for the repository.

Current public docs:

- `product-spec.md` - product goals, scope, and current hypothesis
- `interaction-model.md` - how voice, gaze, confirmation, and feedback fit together
- `safety-model.md` - risk model and broker policy boundaries
- `command-vocabulary.md` - current bounded command set
- `mvp-readiness.md` - tester-facing setup and acceptance targets
- `architecture.md` - runtime structure and repository conventions

Local-only planning, reviews, benchmarks, and working notes have been moved out of `docs/` into `.private-docs/`, which is ignored by git and not intended for public sync.
